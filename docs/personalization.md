# Personalization

Use facts the receiving AI actually knows, and ask when uncertain. Customize site/config.mjs display identity and supported HTML fields. Keep stable IDs, schema and behavior contract intact. For portfolio, use relevant real names, descriptions and preferences only with user intent; never invent history, customers, results, testimonials or contact details. User color/type preferences can be applied through a named app semantic theme; preserve accessibility and document exceptions to defaults. Connection credentials belong only in private runtime.
